How it plays

A simple loop: choose, practice, play, progress.

The structure is straightforward enough for new learners, but rich enough to keep returning users improving over time.

01

Pick a topic and level

Game cards show category, subject, level, play time, entry cost, and reward range before a learner starts.

02

Practice first if needed

Practice mode removes credit pressure, so learners can warm up and understand the format before real play.

03

Play timed quiz rounds

Real play uses entry credits, gives up to three tries, and rewards accuracy with stronger returns on earlier wins.

04

Build streaks and level up

Wins grow streaks within each category-subject-level path. Enough consecutive wins unlock the next level.

Game sessions can be resumed

The game state is stored on the server, so an interrupted session can be picked up again instead of being lost.

Hints and answer flow stay dynamic

Hints help when a learner is stuck, and answer options can reshuffle after a wrong move to keep guessing less effective.

More ways to play

Four game formats. All on the same credit and level system.

Beyond timed question rounds, Know To Win offers crossword, Sudoku, and an arithmetic slot-machine. All formats feed the same level and credit system, so progress is never siloed.

Quiz

Timed quiz rounds

The core gameplay loop. Choose a topic and level, play timed rounds, earn credits on wins. Up to three attempts per game with better rewards for earlier victories.

Crossword

Word-based crossword grids

Server-generated crosswords calibrated to the learner's school level and language proficiency. Clues can be bilingual. Every grid is unique — the same grid is never served twice.

Sudoku

Logic grids, four difficulty bands

Standard 9×9 Sudoku generated on-demand across four levels: Easy (~46 clues), Medium (~36), Hard (~31), and Evil (~26, the hardest offered). Each puzzle has exactly one solution.

Maths

Arithmetic equations as a slot-machine

An 8-column grid where each column spins independently. Align the columns to form valid equations using +, −, ×, or ÷. Easy mode uses single digits; hard mode uses two-digit numbers.

Live learning sessions

Book a micro-tuition session directly in the app.

Know To Win connects learners with verified tutors and session moderators for short, structured live sessions. The tutor and moderator must hold the relevant certification and support the requested language before a booking can go through.

01

Select subject, level, and language

The platform matches available certified tutors and moderators based on your selection.

02

Reserve a time slot

A slot is reserved for all three parties — learner, tutor, and moderator — simultaneously.

03

Join the live session

The meeting link is provided after booking. Sessions may be recorded for later review.

04

Rate and review

Learner, tutor, and moderator all leave a rating after the session ends.

Session types

Sessions can be scoped as education, certification prep, quiz support, game coaching, or a seminar — each mapped to the appropriate subject track.

Credit-based session fee

Sessions carry a configurable credit cost using the same four credit pools used across the rest of the platform: earned, donated, referral, or purchased.

Fully auditable lifecycle

Every lifecycle change — created, notified, in progress, completed, cancelled — is timestamped and the session state can be resumed if interrupted.

Credits and rewards

Gameplay stays flexible. Rewards stay earned.

Different kinds of credits make it easier to enter and keep playing, but rewards are deliberately tied to actual wins.

The four credit pools

Referral

Credits earned from inviting new users and bringing friends into the app.

Donated

Credits received from others and used to keep gameplay going.

Earned

Credits won through successful play. These are the ones that matter for prize booking.

Purchased

Credits bought to continue playing when a learner wants a faster top-up.

How prizes work

  1. Win games and build earned credits.
  2. Complete profile, address, and verification requirements.
  3. Add digital or physical prizes to the cart.
  4. Book during checkout windows using earned credits.
Important:

Only earned credits can be used to book prizes. Other credit types can still be used to enter games.

Institutional access

Schools and colleges can maintain their own learner groups.

Educational institutions can register on Know To Win and manage a dedicated learner group. Members who join through the school's join code are added automatically — no manual enrolment required.

School profile

Name, type, grades offered, curricula (CBSE, IGCSE, IB, state board), academic session, website, and language settings are all captured at registration.

Learner group via join code

Every registered school has a primary learner group. Students join via a short code and are added automatically — no per-student admin action needed.

Editor access

Schools can assign editors — users who can update the school record and moderate group membership without needing platform-level admin access.

Adoption tracking

Schools are tagged by management type (Government / Aided / Private), location (Urban / Rural), and size — with lifecycle stages tracked from pilot to active.

FAQ

The main questions people ask before they start.

Can I practice without spending credits?

Yes. Practice mode lets learners play without spending entry credits and without generating rewards.

What game types are available?

Know To Win currently offers four game formats: timed quiz rounds, crossword puzzles calibrated to school level and language, Sudoku with four difficulty bands, and a maths equations slot-machine. All four run on the same credit and level system.

What happens if I lose a game?

A loss does not always wipe out the entire entry fee. Part of the fee can be refunded to the same credit type, depending on the rules in play.

Which credits can book prizes?

Only earned credits can book prizes. Referral, donated, and purchased credits can still be used to enter games.

Can my school use the platform as a group?

Yes. Schools and colleges can register an institutional profile and issue a join code. Students who join through that code are automatically added to the school's learner group.

Can I apply for an education loan through the app?

Yes. The platform includes a structured loan application module. Once submitted, the application is routed to a designated loan provider by the platform team. All personal and financial data is encrypted at rest.

Are prizes only digital?

No. The prize system supports both digital and physical rewards, with booking and delivery handled through the order flow.

Can a running game be resumed later?

Yes. The app stores game state on the server, which makes it possible to return to a running session after an interruption.

Where do I open the app?

The live web app runs at app.knowtowin.com. An Android app is also available — see the downloads page.

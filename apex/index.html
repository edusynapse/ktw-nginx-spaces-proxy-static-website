Credits system

Credits make gameplay flexible, but earned credits carry the deepest value.

Any credit type can fund a game entry. Prize booking stays stricter: only earned credits can be turned into prize orders.

Referral credits

Acquired through invite links and follow-on friend activity. Useful for getting new users into the loop quickly.

Donated credits

Gifted by others and directed straight into playability, with expiry pressure encouraging faster reuse.

Earned credits

Generated by wins, kept without the same expiry pressure, and used for prize booking. This is the platform’s core reward currency.

Purchased credits

Bought through supported payment flows to keep momentum going when users want a faster top-up path.

What happens on a win?

Reward credits are added to the earned credits pool, which means successful play strengthens both future gameplay capacity and future prize eligibility.

What happens on a loss?

The entry fee is not simply wiped out. A percentage can be refunded to the same credit type, which softens the downside and keeps replay viable.

Prizes and orders

Rewards are not just decorative. They convert into a clear order flow.

The prize model supports both digital and physical rewards, while keeping booking gated by profile completeness, address validity, verification, and checkout timing.

Digital and physical prizes

Users can work toward fast-delivered digital rewards or physical items that go through shipment and tracking.

Earned credits only

Prize orders are funded through earned credits only, which keeps the reward economy tied to actual performance.

Checkout windows

Cart items convert into orders during defined windows, with tag rules and eligibility checks deciding what can be booked.

Refund-aware system

Out-of-stock items, approved returns, or failed fulfillment can send earned credits back instead of trapping value.

Booking flow at a glance

  1. Win games and build earned credits.
  2. Complete profile, address, and verification requirements.
  3. Add prizes to cart and wait for the relevant checkout window.
  4. Convert eligible cart items into orders and track status afterward.

FAQ

Questions people usually need answered before they enter the app.

Can users practice without spending credits?

Yes. Practice mode allows repeat play without using entry credits and without generating rewards, which makes it useful for warm-up and revision.

Which credits can book prizes?

Only earned credits can book prize orders. Referral, donated, and purchased credits can still be used to enter games.

What if a learner loses a game?

A loss does not always mean the whole entry fee is lost. Part of the fee can be refunded back to the same credit type, depending on the rules for that credit source.

How are prizes actually claimed?

Users add eligible items to cart, satisfy profile, address, and verification conditions, and then book during checkout windows using earned credits.

Does the app preserve an active game session?

Yes. The gameplay state is stored on the server so a running game can be resumed if the session is interrupted.

Which browser should web users prefer?

The web app is designed for Chrome-based usage today. This public page is lightweight, but the live app experience should be opened in a supported browser.
